# IP logo

- `ip_logo.png`: the logo, lime on transparent (457 x 463). The panel firmware logo (`panel/tools/logo_to_lvgl.py`) and
  the screen picture in the case renders are made from it.
- `ip_logo_dark.png`: the same logo in black, for light backgrounds.
- `ip_logo_contours.json`: the logo traced into outlines by `case/scripts/logo_trace.py`. The case model debosses it into
  the right side wall.

The logo is my brand and is not covered by the code license.
