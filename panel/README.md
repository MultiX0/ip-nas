# Touch screen

The 3.5" screen in the front of the case: `firmware/` runs on the screen (PlatformIO, LVGL), `pi_agent/` runs on the Pi
and feeds it over USB, `tools/` has a PC test tool and the logo converter, `screenshots/` the pictures used in the docs.

How to build, flash and install all of it: [docs/PANEL.md](../docs/PANEL.md).
